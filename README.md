The Calender will show you your class number (also some VK classes), teacher name and the subject name.

STEP 1A — PICK A WEEK (you can only select up to 4 weeks and you have to do them individually, the code was very unstable when exporting all four weeks together.)
STEP 1B — YOUR GROUPS (Choose your english group and then your second language)
STEP 1C — YOUR CLASS (Select your class)
STEP 2A — OPEN EDUPAGE (Go to https://torg.edupage.org/timetable/ and open inspect element) 
STEP 2B — Copy the code into console tab
STEP 2C — After DONE! appears run the other part of the command
STEP 3 — Paste the result into the text box


Google Calendar: calendar.google.com → Settings (gear) → Import & export → Import
iPhone: Email or AirDrop the .ics to yourself → tap it → tap "Add All"
Outlook: File → Open & Export → Import/Export → Import an iCalendar (.ics) file

Note:
One-time import — repeat each week for updated lessons.
PLEASE ALSO NOTE: If timetable changes the new info won't come over until you redo all of the steps. So i advice to use it in two weeks in advance.
